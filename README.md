# Lacre Frontend

Painel operacional da Lacre para acompanhar a volta de canhotos e reduzir o tempo entre a entrega e a cobrança.

## Stack

- Next.js 16.3 com App Router
- React 19
- TypeScript
- CSS responsivo sem biblioteca visual externa

## Executar localmente

```bash
npm install
npm run dev
```

Acesse `http://localhost:3000`.

## Interface implementada

- navegação e faixa de comandos inspiradas na hierarquia do Microsoft Word;
- resumo diário com exposição financeira antes das listas operacionais;
- filtros, busca, seleção e visualização dos comprovantes;
- criação de acompanhamento e ações simuladas de cobrança/exportação;
- visualização documental do comprovante Lacre;
- layout adaptado para desktop, tablet e celular.
